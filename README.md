# 字母探险家 · Alphabet Explorer

面向学前儿童的英语字母与单词互动学习应用。包含认识字母、听名找字母、大小写配对、描写练习、自然拼读和家长练习模式。

## 本地运行

无需安装依赖或构建。使用 Python 3 启动静态服务：

```sh
python -m http.server 8000 --directory dist
```

打开 `http://localhost:8000`。

## 部署

将 `dist/` 中的全部文件部署到任意静态网站目录即可。资源使用相对路径，支持子目录部署。无需配置账户、数据库或 API 密钥。

## 检查

安装 Node.js 后，在项目根目录运行：

```sh
node scripts/check-phonics.mjs
```

## 数据与隐私

学习进度、星星和错题保存在使用者自己的浏览器 localStorage 中；本仓库不包含实际学习记录。家长指南提供清除本机记录的入口。应用不录制儿童声音。

完整单词发音依赖有道在线词典，播放时浏览器会向该服务发送对应单词的音频请求；相关网络请求也会向服务提供方暴露常规连接信息。字母名称和拼读示范使用随项目保存的音频。

仓库仅包含应用代码、教学数据、音频和来源说明，不包含原部署账户配置、个人域名、服务器信息、凭据或原项目的 Git 历史。

## 音频来源

第三方素材的来源及授权说明见 `dist/audio-credits.html`、`dist/phonics-credits.html` 和音频目录中的 `credits.json`。请保留素材署名与授权信息；本项目不改变第三方素材原有授权。
